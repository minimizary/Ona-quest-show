# ONA QUEST — THE EXPERIENCE

Интерактивная презентация для команды и руководства ONA Foundation.

## GitHub Pages

1. Создайте новый репозиторий, например `ona-quest-experience`.
2. Загрузите `index.html` в корень репозитория.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите `main` и `/ (root)`, затем Save.
5. После публикации ссылка появится в разделе Pages.

Сайт статический, не требует токенов API, сервера или базы данных. Все имена и механики демонстрационные. Клавиши ← и → переключают слайды.
